# 📄 Employee Data Viewer

A simple web application to display employee data using HTML, CSS, and JavaScript. This app creates styled employee cards and displays them dynamically when a button is clicked.

---

## 🚀 Features

- Display employee information in a card-based layout.
- Toggle visibility of employee data with a single button.
- Responsive design using Flexbox for better layout on various screen sizes.

---


## 📋 How It Works

- An array of employee objects is defined in JavaScript.
- When the user clicks the **"Get Employee Data"** button:
  - The data is dynamically rendered as individual cards.
  - If data is already displayed, clicking again will clear the view.
- The UI is styled with basic CSS for readability and structure.

---

## 🖥️ Technologies Used

- HTML5
- CSS3 (Flexbox for layout)
- JavaScript (DOM Manipulation)
